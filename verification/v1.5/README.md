# 1.5.0 驗證紀錄

已完成網頁建置、10 項資料單元測試、12 組小量瀏覽器檢查及 3 組搬移／交易失敗檢查，結果均通過。詳細結果見同目錄 JSON 及文字紀錄。

驗證包含活動網址驗證與保存、兩個新增按鈕、全部收合與展開、圖片選擇與 contain、灰框空心及 #F8D985 實心星號、分類色與未分類灰色、既有攤位／商品操作、備份及重新載入。瀏覽器使用獨立資料，不變更使用者預覽資料。

商品卡片改為名稱與星號同列，價格、分類及狀態分層；完整預覽見 preview-list.png。活動網址為選填欄位，備份格式仍為 2，舊資料無此欄位仍可使用。

Android 已完成 preview.2（1.5.0-preview.2 / 5）編譯、簽章驗證、套件名稱與獨立 Provider 檢查、所有封裝網頁資源對照。未啟動模擬器、未執行 Android 裝置測試或高負載測試。Android 選圖、分享及觸控仍待使用者同意後以裝置驗證。

最新修改：星號篩選文字兩種狀態皆為 #B58900，收合向量圖示與文字對齊，編輯鉛筆與星星同列。既有瀏覽器測試已於圖示修改後通過；最終文字顏色於封裝 CSS 檢查確認，尚未做手機畫面驗證。舊截圖為先前介面快照，最終外觀以 src 與 dist 為準。
